lifecycle_manager_navigation이 가장 높은 CPU를 사용했다. lifecycle 상태 조회, DDS 통신, logging 또는 executor wake-up이 과도한지 추가 측정할 가치가 있다.

Agent가 담당하는 역할

로봇 domain ↔ 관제 domain 브리지

  • 두 개의 ROS 2 context와 executor thread로 domain을 분리한다.
  • 관제 명령을 queue에 넣고 로봇 executor에서 안전하게 재발행한다.
  • AMCL pose, 배터리, 태그 및 도킹 상태를 관제 domain으로 전달한다.

상태와 heartbeat

  • 현재 위치·yaw·배터리·모드 스냅샷을 관리한다.
  • 2 Hz로 /robots/heartbeat를 발행한다.
  • 재측위와 도킹 결과 이벤트를 관제에 전달한다.

명령·안전 관리

  • 원격 cmd_vel, 모드, initial pose 명령을 로봇 domain으로 중계한다.
  • 20 Hz queue drain과 0.3초 수동 명령 watchdog을 수행한다.
  • 재측위 detector와 도킹 process의 시작·timeout·종료를 관리한다.

Agent 자원 판단: 평균 CPU 9.83%는 단일 코어의 약 1/10, 4코어 전체의 2.46%다. 로봇 전체 CPU 병목의 주원인은 아니며, 77.7 MiB RSS는 두 ROS context, executor, 통신 endpoint 및 session 상태의 비용으로 볼 수 있다.

최근 2주 CPU 튜닝 효과

분석 기간은 2026-07-11~07-25다. 같은 실험 안에서 전후 조건과 수치가 확인되는 기록만 비교했으며, 서로 다른 날짜의 절대값은 직접 비교하지 않았다.

JSP의 base load는 1분 load average이며 프로세스 CPU 백분율이 아니다. 따라서 Bringup CPU 절감률로 환산하지 않았다.

무엇이 실제로 효과가 있었나

가장 확실한 keeper는 Agent 경량화다. 35~55 Hz /tf가 Python executor를 깨우던 구조를 제거해 CPU를 약 70~75% 낮췄고, agent ON 도킹 8→7→9 완주까지 확인했다. 현재 실측 9.83%도 튜닝 후 범위와 대체로 맞는다.

Bringup 계층에서는 실제 엔코더 기반 /joint_states와 겹치는 JSP를 제거해 base load가 2.6에서 2.0으로 낮아졌다. AMCL 자체는 검증된 직접 튜닝이 없으며, 현재 16.24%는 기준값이지 절감 결과가 아니다.

효과가 없거나 아직 채택하지 않은 것

Nav2 controller와 local costmap의 주기를 절반으로 낮춰도 합계 CPU가 줄지 않아 성공 기준인 controller 20 Hz, local 10/2 Hz, global 1/1 Hz로 원복했다. Composition은 peak load를 57.8% 낮춰 가장 큰 잠재 효과를 보였지만 당시 bond와 경로·충돌 계층의 운영 검증이 끝나지 않아 현재 설정으로 채택하지 않았다.

권장 후속 분석

  1. 정지·Nav2 주행·순찰·재측위·도킹 상태를 각각 60초 이상 측정한다.
  2. Agent 단독 실행 비교로 두 DDS context와 20 Hz drain timer의 순수 비용을 분리한다.
  3. lifecycle_manager_navigation의 callback, logging 및 상태 조회 빈도를 확인한다.
  4. vcgencmd get_throttled로 현재·과거 열/전압 스로틀링 플래그를 확인한다.

측정 범위와 한계

  • Bringup은 핵심 bringup process만 포함했다. LiDAR와 상태 publisher는 제외했다.
  • AMCL은 amcl만 포함했고 map server와 localization lifecycle manager는 제외했다.
  • Nav2는 navigation lifecycle manager와 7개 navigation server를 포함했다.
  • RSS 합계에는 shared page가 중복 계산될 수 있다.
  • 현재 운용 상태의 12초 관측값이므로 조건을 통제한 단독 벤치마크와 구분해야 한다.
